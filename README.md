# منصة مصبرات العطاوية – نسخة إصلاح العرض

هذه النسخة تعالج مشكلة ظهور الصفحة كنص وروابط غير منسقة عند عدم تحميل ملفات CSS أو الشعار. تم تضمين التنسيق والشعار والوظائف الأساسية داخل كل صفحة HTML، حتى لا يتوقف التصميم على مسارات ملفات خارجية.

## الصفحات
- الرئيسية: `index.html`
- من نحن: `about.html`
- المنتجات: `products.html`
- الجودة والإنتاج: `quality.html`
- معرض الصور: `gallery.html`
- اتصل بنا: `contact.html`
- نموذج لوحة الإدارة: `admin.html`

## النشر على Vercel
1. فك ضغط المشروع.
2. ارفع **محتويات هذا المجلد كاملة** إلى مستودع المشروع المرتبط بـ Vercel، بحيث يكون `index.html` و`vercel.json` في جذر المشروع مباشرة.
3. في إعدادات Vercel اجعل **Root Directory** هو المجلد الذي يحتوي مباشرة على `index.html`، واترك Framework Preset على Other، وBuild Command فارغاً، وOutput Directory فارغاً أو `.`.
4. أعد النشر (Redeploy) ثم افتح الموقع وحدّث الصفحة تحديثاً كاملاً.
