# مصبرات العطاوية – نسخة تصميم مطوّرة

## ما تم تعديله
- اعتماد صورة اللوغو التي أرسلها صاحب المشروع كما هي في جميع الصفحات.
- إبراز الهوية البصرية بألوان أخضر زيتوني داكن وذهبي وعاجي.
- إعادة بناء الصفحة الرئيسية بتصميم أكثر تميزاً مع إبراز اللوغو.
- إنشاء صفحة مستقلة بعنوان `order.html` لطلب المنتوجات.
- إضافة صفحة طلب المنتجات إلى القائمة الرئيسية وروابط المنتجات والتواصل.
- جعل التصميم متجاوباً مع الهاتف والحاسوب.
- تضمين CSS داخل كل صفحة لتقليل احتمال ظهور الصفحة دون تنسيق عند النشر.

## محتويات المشروع
- `index.html` الرئيسية
- `about.html` من نحن
- `products.html` المنتجات
- `order.html` طلب المنتوجات
- `quality.html` الجودة والإنتاج
- `gallery.html` معرض الصور
- `contact.html` اتصل بنا
- `association-logo.jpg` اللوغو المرسل
