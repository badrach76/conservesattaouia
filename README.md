# منصة مصبرات العطاوية – وحدة إنتاج زيت الزيتون

## محتويات النسخة
- موقع عربي متجاوب متعدد الصفحات.
- هوية أولية متجهية SVG بشجرة زيتون في الوسط.
- صفحات: الرئيسية، من نحن، المنتجات، الجودة والإنتاج، معرض الصور، اتصل بنا.
- تواصل عبر الهاتف وواتساب، مع نموذج يجهز رسالة واتساب.
- تصور أولي للوحة الإدارة في `admin.html`.

## بيانات التواصل المعتمدة
- الهاتف: +212 661 243 720
- العنوان: العطاوية، كلم 3، طريق مراكش–العطاوية

## تشغيل محلي
افتح `index.html` في المتصفح أو انشر محتويات المجلد على استضافة صفحات ثابتة مثل Vercel.

## مهم قبل الإطلاق الفعلي
هذه نسخة واجهة أولية وليست نظام إدارة إنتاجياً. صفحة `admin.html` توضيحية فقط ولا تحتوي على مصادقة أو تخزين آمن. قبل استعمالها علناً يجب:
1. ربط قاعدة بيانات (مثلاً Supabase) وجداول المنتجات والطلبات والوسائط والمحتوى.
2. تفعيل تسجيل دخول إداري حقيقي مع صلاحيات وخاصية استعادة كلمة المرور.
3. تطبيق سياسات RLS والتحقق من المدخلات وحماية مفاتيح الخادم.
4. بناء لوحة إدارة فعلية لرفع الصور وتحرير المحتوى ومتابعة الطلبات.
5. إدخال الشعار النهائي والصور الحقيقية للمعصرة والمنتجات، ومراجعة نصوص الجودة والاعتمادات.

لا توجد أسعار أو شهادات أو ادعاءات جودة غير موثقة في هذه النسخة.
